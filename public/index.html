How to run this, and what the numbers mean

While you use your PC

Start the server and leave its window open or minimized. You can game normally. This browser tab can be closed; the server does the work.

Sleep, shutdown, closing the server or losing internet stops observation. Start it again to resume saved wallets. Monitoring gaps are recorded; missed buys are not replayed.

When do trades happen?

Bitcoin trades around the clock. The 4-hour bot checks at 1, 5, 9 AM and 1, 5, 9 PM Pakistan time. The daily bot checks at 5 AM. Actual decisions happen on the next successful market check.

Run 24/7 for a continuous experiment. Gaming hours only means an intermittent test with missed decisions. Cloud hosting can run while your PC is off.

Independent fake wallets

Each starts with 1,000 USDT and uses 20% of cash per buy. Buy & hold buys once. Profit includes unsold BTC valued at the latest observed price.

Costs assumed: 0.1% fee and 0.05% adverse price adjustment per side. Pausing blocks new buys; trend exits continue. No API keys or real money are connected. Backtests are on the Research page.
